# Monkeyspeak

Practice turning an idea into a clear spoken prompt, fast.

The idea: see a challenge, think, speak your prompt, and get feedback on speed and effectiveness. Browser speech recognition and a small local model are the intended direction. This repository currently holds the planning entrypoint.

Monkeyspeak is a working name. Join the [naming workshop](https://github.com/mia-cx/monkeyspeak/issues/8) to help choose it.

## Start contributing

Open [Find the way to the first spoken-prompt practice game](https://github.com/mia-cx/monkeyspeak/issues/1). Its child issues cover the open decisions and investigations.

Choose an unassigned child with no open blockers and assign yourself before starting. Each ticket states its question and completion criteria. HITL means a human joins the discussion; AFK means the investigation can proceed independently.

The map holds the workflow and decision index. [DIRECTION.md](DIRECTION.md) holds the project's direction.
